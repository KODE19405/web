🌐 DNS Gratis & Tercepat

Pilihan server DNS publik yang cepat, stabil, dan aman dari pemblokiran. Klik salin untuk menggunakan.

Cara Menggunakan DNS di Perangkat Anda:
  • • Android: Pengaturan → Jaringan & Internet → DNS Pribadi → Pilih "Nama Host Penyedia DNS" → Tempel hostname.
  • • Windows: Pengaturan → Jaringan & Internet → Wi-Fi / Ethernet → Properti → Edit Penetapan Server DNS.
  • • iPhone / iOS: Pengaturan → Wi-Fi → Ketuk ikon (i) → Konfigurasi DNS → Pilih Manual → Tambah Server.

🕵️ Web Recon & IP/Port Finder

Cari alamat IP server, catatan DNS, port utama web, serta rincian header HTTP target.

Tips Singkat Penggunaan:
  • • Gunakan nama domain tanpa http:// (misal: google.com atau IP 8.8.8.8). Tekan Enter untuk memproses.
  • • Fitur ini membantu tahap awal reconnaissance untuk memetakan IP target & DNS sebelum pengujian jaringan.

⚡ OWASP ZAP (Zed Attack Proxy)

Panduan penggunaan dan generator perintah pemindaian keamanan aplikasi web berbasis OWASP ZAP.

🛠️ CLI Command Generator

zap-baseline.py -t http://example.com -g gen.conf -r report.html
Tips Singkat Pemakaian ZAP:
  • • Mode GUI: Buka ZAP desktop → Masukkan URL di Automated Scan → Klik Attack untuk pemindaian cepat.
  • • Mode CLI/Docker: Salin perintah di atas untuk otomasi CI/CD atau audit terjadwal via terminal.
  • • Mulai selalu dengan Baseline Scan agar tidak mengganggu kinerja server target.

🟠 Burp Suite Community

Panduan konfigurasi Proxy Interceptor, Repeater, dan Decoder untuk audit keamanan web secara praktis.

🌐 Quick Setup Browser Proxy

Atur Proxy HTTP browser Anda ke alamat lokal berikut untuk mengintersepsi trafik lalu lintas:

IP: 127.0.0.1 | Port: 8080
Tips Singkat Pemakaian Burp Suite:
  • • Tekan tombol Open Browser di tab Proxy -> Intercept (menggunakan browser bawaan Burp).
  • • Aktifkan Intercept is on untuk menahan dan mengedit request HTTP sebelum terkirim ke server.
  • • Klik kanan request → Send to Repeater (Ctrl+R) untuk uji coba pengiriman payload secara cepat.

🔍 Nmap (Network Mapper)

Generator perintah audit port & analisis layanan jaringan menggunakan Nmap CLI.

⚙️ Command Generator

nmap -F 127.0.0.1
Tips Singkat Pemakaian Nmap:
  • • Gunakan -F untuk cek 100 port paling umum terlebih dahulu (hemat waktu).
  • • Gunakan -sV untuk mengetahui versi aplikasi yang berjalan di balik port terbuka.
  • • Pada Linux/Mac, jalankan dengan sudo nmap untuk pemindaian mode Stealth (SYN Scan).

🌐 Nikto Web Server Scanner

Generator perintah pemindaian konfigurasi server dan file sensitif berbahaya dengan Nikto CLI.

⚙️ Command Generator

nikto -h example.com -p 80
Tips Singkat Pemakaian Nikto:
  • • Jalankan di terminal untuk memindai direktori tersembunyi (seperti /admin, /config, .env).
  • • Tambahkan opsi -ssl di akhir perintah jika server menggunakan enkripsi HTTPS.

🗄️ SQLMap

Generator perintah dan acuan parameter pengujian kerentanan SQL Injection pada aplikasi database.

⚙️ Command Generator

sqlmap -u "http://example.com/page.php?id=1" --level=1 --batch --dbs
Tips Singkat Pemakaian SQLMap:
  • • Salin perintah CLI lalu jalankan di Terminal / Command Prompt yang terinstall Python.
  • • Parameter --batch berguna agar SQLMap tidak terus-menerus meminta jawaban manual (Y/N).
  • • Gunakan --dbs terlebih dahulu untuk memastikan nama-nama database sebelum mengekstrak tabel.
